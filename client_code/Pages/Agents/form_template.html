How agents work in a crew
GroomHumans write criteria and run the gates. Cards that gate AGENT SOLO or AGENT + HUMAN and pass the Definition of Ready are fair game.
PullThe agent asks for next: the top Ready card that fits it, with a full markdown brief.
ClaimIt claims the card (its own WIP limit and the crew's Doing limit both apply) and logs as it works.
Hand inIt ticks criteria and submits with a summary and PR links. The card moves to Review.
ApproveA human reviews and moves it to Done. Agents never do. Review is where the WIP limit bites first.
